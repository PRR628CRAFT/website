## Context

### What is Pterodactyl?

[Pterodactyl](https://pterodactyl.aio) is a popular hosting panel written in PHP, React, and Go. It has been widely used since 2015 by massive hosting companies, homelabs, and everyone in-between. WIP

## What is Blueprint?

[Blueprint](https://blueprint.zip) is a modding framework for Pterodactyl. It provides an API for developers to install extensions. Extensions can add new features, themes, and more. This was a gap in what Pterodactyl V1 could provide which Blueprint filled very well.
